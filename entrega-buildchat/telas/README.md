# Telas

Capturas tiradas do sistema em produção, com uma conta real de atendente
(perfil comum, não administrador). A descrição de cada uma está em
[../05-telas.md](../05-telas.md).

As telas da extensão aparecem sobre o WhatsApp Web na tela de conexão (o QR),
porque a captura foi feita sem uma sessão de WhatsApp conectada. O que importa
nelas é a interface do BuildChat, não o conteúdo do WhatsApp ao fundo.
